# Contributing

Thank you for helping improve the companion to *AI-Native Quality Engineering*. Corrections, clearer wording, and reports that a lab step no longer matches the tools are all welcome.

## Before you open an issue

Include:

- the book edition (for example, First Edition, 2026)
- the chapter, lab, or template name
- what you expected and what you saw
- for a lab problem: your VS Code and GitHub Copilot versions

## Before you open a pull request

Every contribution must follow the same rules as the book.

1. **No confidential material.** No employer, client, product, repository, or person names. No internal URLs, machine paths, or screenshots of internal tools.
2. **No secrets or real data.** Use synthetic, fictional, or clearly sanitized data only.
3. **Label every example.** Mark it as illustrative, composite, synthetic, or production-derived and sanitized.
4. **No invented numbers.** Do not add benchmarks, percentages, or results you cannot source. Label illustrative numbers as illustrative.
5. **Keep controls in code.** Do not present a prompt or instruction file as a security boundary.
6. **Plain English.** Short sentences. Explain a term before its abbreviation. No em dashes.
7. **Update the changelog.** Add a line to [CHANGELOG.md](CHANGELOG.md).
